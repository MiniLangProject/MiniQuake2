## GameImport

```ml
struct GameImport
```

Function-valued form of game_import_t. Variadic C print functions take one already-formatted MiniLang string. collisionWorldReady is the sole appended MiniQuake2 extension: asset-free test/runtime graphs can distinguish their intentional lack of a BSP hull from an ordinary unobstructed trace.
